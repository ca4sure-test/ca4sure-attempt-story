CA4SURE Attempt Story Landing Page

Files in this folder:
- index.html: responsive landing page
- ca4sure-logo.png: CA4SURE logo

Publish on GitHub Pages:
1. Create a NEW public GitHub repository, e.g. ca4sure-attempt-story.
2. Upload index.html and ca4sure-logo.png to the repository root.
3. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.
5. After publishing, GitHub shows the live site URL in Settings > Pages.

Buy Now buttons currently open WhatsApp with the selected plan pre-filled, because a direct checkout/payment link was not supplied.
